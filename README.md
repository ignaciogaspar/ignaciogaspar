### 🧭 Lo que hago

- 🌐 **Full-stack:** APIs en NestJS y FastAPI, frontends en React y Next.js, y PostgreSQL con Prisma.
- 🤖 **IA aplicada:** sistemas multiagente, RAG y memoria hechos a mano, servidores MCP, y LLMs con visión (Claude, OpenAI y Gemini).
- 📈 **Machine learning:** detección de objetos con YOLO y RF-DETR, y modelos predictivos sobre telemetría.
- ☁️ **Cloud y DevOps:** AWS (CloudFormation, ECR), Docker, CI/CD con GitHub Actions, DevSecOps (gitleaks, Trivy, Semgrep y OWASP ZAP) y observabilidad con New Relic.
